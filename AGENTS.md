## Agent skills

### Issue tracker

Issues for this repo are tracked in GitHub Issues and should be accessed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default five-label triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context domain-docs layout rooted at `CONTEXT.md`, with ADRs under `docs/adr/`. See `docs/agents/domain.md`.
